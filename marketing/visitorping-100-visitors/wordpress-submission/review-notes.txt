VisitorPing connects WordPress to a hosted website analytics and notification service. The plugin code is MIT-licensed; collection, storage, dashboard display, and push delivery are supplied by the external service. The connector itself is free. The hosted service requires an account and offers a 14-day trial, then paid access from US$19/month.

External domains and collected data are documented in readme.txt. No tracker loads before a valid Site Key is configured. Administrators can control exclusions, and developers can suppress tracking with visitorping_should_track. Optional signed content delivery is disabled by default and publishing is separately opt-in.
