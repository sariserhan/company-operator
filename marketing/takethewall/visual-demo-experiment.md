# Next acquisition experiment: show the takeover

User stopped directory submissions. Budget remains $0. No directory badges or
reciprocal footer links. No analytics queries: user owns measurement.

## Why this test

The existing app already provides owner sharing, public takeover pages, and image
cards. Those help distribute an existing owner's takeover, but require owners to
start with. The next test targets the initial audience through a visual explanation.
This is a hypothesis, not a promise of reach or conversions.

## First creative: 15-second video

- 0–3 seconds: “What if a website had only ONE spot?” Show a single wall.
- 3–8 seconds: Show example message A replaced by example message B. Keep
  “DEMO — example takeovers” visible throughout staged footage. Do not activate
  production purchases, impersonate customers, or show invented visitor counts.
- 8–12 seconds: “The next takeover replaces it. What would you put here?”
- 12–15 seconds: “See who owns the wall → takethewall.com”.

Caption: “I built a website with one spot. The next takeover replaces whoever is
there. What would you put on it? https://takethewall.com/?utm_source=x&utm_medium=organic_social&utm_campaign=wall_demo&utm_content=takeover_video”

Avoid prize/earnings claims, fake testimonials, price-led hooks, and claims that
paid takeover participation is free. The destination explains purchase terms.

## Distribution

Prepare the video first; publish through the existing connected X account using
Buffer. This file is a storyboard only: no video rendered or post scheduled yet.
Do not claim access to TikTok, Instagram, or YouTube accounts. Adapt for those
channels only if an authorized publishing connection becomes available.

Judge the experiment using the user's reported external visitors and qualitative
replies. Do not run traffic monitoring. Do not repost identical creative repeatedly.
Owner sharing is the next step once external participants actually take the wall.
